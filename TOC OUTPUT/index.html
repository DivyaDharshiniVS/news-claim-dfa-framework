A. Finite Automata Representation of Claims

In classical computing, Finite Automata process strings of characters. In this framework, we model the epistemic lifecycle of information as discrete states, and journalistic events as input alphabet tokens.

  • Discrete State Space: A news claim cannot exist in infinite arbitrary conditions; it resides in exactly one state from the finite set Q at any time step.
  • Temporal Invariance: Given identical evidence sequences, a deterministic machine always arrives at the identical verification outcome.
  • Mathematical Auditability: Prevents subjective or hidden decision making by strictly defining allowed transition paths.

B. Formal 5-Tuple Definition of the DFA

The framework is formally defined as a Deterministic Finite Automaton:

M = (Q, Σ, δ, q₀, F)
  • Q (Finite States): { Q0, Q1, Q2, Q3, Q4, Q5 }
  • Σ (Input Alphabet): { a, b, c, d, e }
  • δ (Transition Function): δ: Q × Σ → Q
  • q₀ (Start State): Q0 (Original Claim)
  • F (Accepting States): { Q4 } (Verified Claim)

D. Transition Function δ Dynamics

The transition function dictates state traversal without ambiguity:

δ(Q0, a) = Q1 | δ(Q0, b) = Q2 | δ(Q0, c) = Q3 δ(Q1, b) = Q2 | δ(Q1, c) = Q3 | δ(Q1, a) = Q1 δ(Q2, d) = Q4 | δ(Q2, c) = Q3 | δ(Q2, a) = Q1 δ(Q3, e) = Q5 | δ(Q3, b) = Q2 | δ(Q3, a) = Q1 δ(Q4, σ) = Q4 (Accepting Sink / Terminal Verified) δ(Q5, σ) = Q5 (Rejecting Sink / Terminal Debunked)

Note: Q4 and Q5 act as absorbing (sink) terminal states once legal consensus or decisive falsification occurs.
